# v2.1.2

This package no longer takes over your `codex` command.

## Fixes
- We were installing a global `codex` bin that clashed with the official Codex installs (npm, native, Homebrew). Whichever installed last won. That bin is gone.

## Heads up
- The two commands you use are unchanged: `codex-multi-auth` for account management and `codex-multi-auth-codex` for the forwarding wrapper.

## Upgrade
```bash
npm i -g codex-multi-auth
```
