# v2.0.0

Adds the rotation proxy, so you can switch between accounts without restarting your session.

## What's new
- Before, switching accounts meant restarting Codex. The rotation proxy now switches mid-session when an account hits a quota limit, needs a token refresh, or the network hiccups.
- Works for both the CLI and the Codex app.
- It only listens on localhost and needs a local client key.
- `bind-app` routes the Codex app through the proxy, and `unbind-app` restores your config.
- Sessions run against a shadow `CODEX_HOME` and sync changes back on exit, so your real Codex state isn't disturbed.

```bash
codex-multi-auth rotation enable      # opt in
codex-multi-auth rotation status
codex-multi-auth rotation bind-app    # route the Codex app through it
codex-multi-auth rotation unbind-app  # and back
```

## Fixes
- The proxy no longer leaves a stale `content-encoding` header on responses it decoded.

## Upgrade
```bash
npm i -g codex-multi-auth
```
