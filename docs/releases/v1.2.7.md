# v1.2.7

Works with Homebrew and release-binary installs of Codex, not just npm ([#391](https://github.com/ndycode/codex-multi-auth/pull/391)).

## What's new
- The wrapper now finds the official Codex CLI on your `PATH`, so Homebrew and downloaded-binary installs work.

## Fixes
- Avoids a self-wrapper loop on POSIX and the wrong `codex.exe` winning on Windows.

## Upgrade
```bash
npm i -g codex-multi-auth
```
