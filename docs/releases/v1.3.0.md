# v1.3.0

You can now ask "why did it pick that account?" and get an answer.

## What's new
- `codex-multi-auth why-selected` explains what went into the account choice.
- `codex-multi-auth verify --paths` checks path safety.
- A feature-flagged routing mutex makes concurrent account selection safer. It's off by default, so nothing changes unless you turn it on.

## Fixes
- A post-audit hardening pass covering OAuth URL redaction, a single source of truth for the redirect URI, hybrid-selector null handling, short-`429` retry ordering, active-pointer normalisation, atomic recovery writes, storage reset ordering, config-conflict surfacing, and malformed SSE warnings.
- Storage JSON parsing is now schema-validated, and the settings hub was split into smaller modules.

## Upgrade

```bash
npm i -g codex-multi-auth
```
