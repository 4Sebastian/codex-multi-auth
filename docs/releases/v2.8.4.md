# v2.8.4

`codex app-server` now works with account rotation on. Rotation is on by default, so before this it was broken for most people.

## Fixes
- `app-server` no longer fails to start with `socket directory path exists and is not a directory` on machines that ran it before.
- Clients now see your real thread list, and threads the server creates are kept instead of thrown away on exit.
- `app-server` now uses your real Codex home, like the TUI (since v2.8.0) and `resume`/`fork` (since v2.8.1). Rotation still applies and your `config.toml` is never touched.
- A short-lived server no longer leaves a helper process running for 12 hours after it exits.
- Commands started by `app-server` are rotated again. Before, it quietly set `CODEX_MULTI_AUTH_RUNTIME_ROTATION_PROXY=0` on them, so they billed whatever account the official CLI picked.
- On Windows, `app-server` no longer copies the ~100 MB Node binary on every launch.
- If the rotation helper can't start, you get a one-line error instead of a stack trace.

## Heads up
- If the helper can't start, the server now fails on purpose. Silently losing rotation would bill the wrong account without you knowing.
- If you set `CODEX_MULTI_AUTH_RUNTIME_ROTATION_PROXY=0` to get app-server working, remove it. It only worked by turning rotation off.
- Codex rejects a socket path whose parent is a symlink, so `--listen unix:///tmp/x.sock` fails on macOS (`/tmp` links to `/private/tmp`). Use a real path.
- `app-server` no longer creates a shadow home or shim directory. It reads and writes your real home.
- Its rotation helper stops when the server exits instead of idling out. The TUI works the other way, and that's deliberate.

## Upgrade
```bash
npm i -g codex-multi-auth
```

To check it worked, start a server. It should start and clients should see your existing threads:

```bash
codex-multi-auth-codex app-server --listen unix:///tmp/codex-app-server.sock
```

To drop the old workaround:

```bash
unset CODEX_MULTI_AUTH_RUNTIME_ROTATION_PROXY
codex-multi-auth rotation status
```
