# v2.3.0-beta.3

Fixes a streaming stall for slow clients and a dedup bug, plus a security fix and cleanup. Includes everything from beta.2 and the drain-first feature from beta.0.

## Fixes

- Streaming no longer stalls or buffers without limit when a client reads slowly. It now waits for the client to catch up before pulling more from upstream.
- Account dedup now repeats until nothing changes, so merging duplicates can't leave behind a new duplicate of an earlier entry.

## What's new

- Removed 852 lines of dead code (seven unused modules) and added a dead-code check to keep it that way.
- Two startup guards and one config abort now throw typed errors with machine-readable fields, so you can branch on the error type. The messages are unchanged.

## Heads up

- Security: temporary filenames for atomic writes now use `crypto.randomBytes` instead of `Math.random()`, so a local attacker who sees one staging path can't predict the next.

## Upgrade

```bash
npm i -g codex-multi-auth@beta
```
