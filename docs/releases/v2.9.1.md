# v2.9.1

A `--cost` budget can't be quietly bypassed anymore, refreshing one account from the login dashboard stops touching the others, and `login` can now re-authenticate a single saved account. Nothing to migrate.

## What's new
- You can re-authenticate one saved account without disturbing anything else ([#679](https://github.com/ndycode/codex-multi-auth/pull/679)):

```bash
codex-multi-auth login --account <index|email|account_id> --preserve-selection
```

- Your active selection, per-family positions and manual `switch` pin stay where they were.
- If you sign in as a different ChatGPT account than the one you named, the write is refused and the old credentials stay.
- Add `--device-auth` on a remote shell. `--account` can't be combined with `--org`.

## Fixes
- A `--cost` budget let unpriced models through as free. For example, two million tokens on `gpt-5.5-pro` against a `--cost 1` cap was allowed because the cap read `$0.00`.
- If a request can't be priced, a `--cost` limit now blocks with `cost limit cannot be evaluated` instead of treating that spend as free. Priced models work as before.
- A plain `login` no longer resets every model family's rotation position to the new account. Families that had moved elsewhere keep their spot.
- `codex-multi-auth login` > Manage > Refresh wrote the refreshed account into `~/.codex/auth.json` even when it wasn't the active one, silently switching the account plain `codex` used. Now it only writes for the account Codex is using.
- Refreshing your active account now does update the native CLI. Before, it could leave it on expired tokens.
- Refreshing a disabled account no longer puts it back into rotation, and the dashboard tells you it's still out.

## Heads up
- Only 7 of the 15 routed model ids have prices, and a `--cost` budget works for them: `gpt-5.2`, `gpt-5.3-codex`, `gpt-5.4`, `gpt-5.5`, `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna`.
- These 8 have no price, so a `--cost` budget blocks them with `cost limit cannot be evaluated`: `gpt-5.4-pro`, `gpt-5.5-pro`, `gpt-5.2-pro`, `gpt-5.4-mini`, `gpt-5.4-nano`, `gpt-5-mini`, `gpt-5-nano`, `gpt-5.1`.
- The missing prices were deliberately not guessed. If you use any of those 8, budget with `--requests` or `--tokens`, which cover every model.

## Upgrade
```bash
npm i -g codex-multi-auth
```
