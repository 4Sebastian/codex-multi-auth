# v2.9.2

A maintenance release. The installed package works exactly like 2.9.1: no runtime, CLI or config changes. This only fixes a repo tooling check.

## Fixes
- `npm run typecheck:scripts` failed on any fresh checkout that hadn't been built yet, because it needed files in the generated `dist/` folder.
- `typecheck:scripts` now runs `npm run build` first, so it works from a clean clone and in CI.
- `CONTRIBUTING.md` now lists `npm run typecheck:scripts` in the local checks to run.
- The CI workflow test is stricter about checking that a build runs before this script.

## Upgrade
```bash
npm i -g codex-multi-auth
```
