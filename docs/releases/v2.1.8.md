# v2.1.8

`switch` now actually sticks, including in the Codex Desktop app.

## What's new
- `switch <index>` pins that account. The rotation proxy uses it ahead of session affinity, health scoring and pool fallback.
- New `unpin` command goes back to normal rotation. `best` also clears the pin.
- `status` shows the pin and warns if the running proxy disagrees.

```bash
codex-multi-auth switch 2     # pin to account 2
codex-multi-auth unpin        # back to normal rotation
codex-multi-auth status       # shows the pin, warns if the runtime disagrees
```

## Fixes
- `switch` now affects the Desktop app.
- The Desktop app no longer stays locked to one account for 20 minutes. Pinning, unpinning or `best` takes effect right away, even for the request in flight.
- Background saves no longer wipe your pin.
- Two CLI processes can no longer overwrite each other's affinity updates.
- `unpin` retries through temporary Windows file locks instead of silently failing.
- A pin no longer leaks between proxy instances.
- `status` no longer shows `Pinned: account NaN` for a corrupt pin. It shows the stored value and points you to `unpin`.

## Heads up
- If your pinned account is unavailable, you get a `503` with `codex_pinned_account_unavailable` instead of being quietly served by another account.

## Upgrade
```bash
npm i -g codex-multi-auth
```
