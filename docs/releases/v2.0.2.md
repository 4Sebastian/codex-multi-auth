# v2.0.2

You can now log in with a device code on machines with no browser.

## What's new
- `--device-auth` is for servers and remote shells where you can't open a browser.
- The login is saved the same way as a browser login.
- Device-code poll responses are kept out of logs and account storage.

```bash
codex-multi-auth login --device-auth
```

## Heads up
- `--device-auth` can't be combined with `--manual` or `--no-browser`. Trying it gives an error instead of ignoring one of them.
- Browser, manual-paste and no-browser logins work the same as before.
