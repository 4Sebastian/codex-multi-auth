# v1.2.2

A freshly refreshed token no longer gets lost when the account pool is saved.

## Fixes
- A token refreshed just before expiry could be overwritten by a concurrent account-pool write, leaving the account with the expired token. Fixed.
- A refreshed token now reliably lands on the account it belongs to.
- Realigned account health handling: healing after a success, guardian penalties, circuit-breaker penalties, reason-scoped rate limiting, and stale cooldown metadata.

## Upgrade

```bash
npm i -g codex-multi-auth
```
