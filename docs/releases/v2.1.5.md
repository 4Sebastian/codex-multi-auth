# v2.1.5

Auto-update is gone, and Codex's SQLite state is now kept separate per runtime session during rotation.

## What's new

- Codex's goal, log and state SQLite files are now isolated per runtime session. Your config, sessions, plugins, skills and multi-auth state are still shared.
- This handles large or locked database files, leftovers from a previous run, Windows sidecar files and path casing differences.
- Update checks no longer run on the Codex launch path, so they can't slow down or interfere with starting a session.

## Fixes

- `thread/goal/get` now returns `{ "goal": null }` for recoverable upstream errors and exhausted pools, instead of showing noisy goal-read errors in the Codex TUI.

## Heads up

- No more auto-updating. The package no longer updates itself or changes the global install. It just prints a notice when a newer version exists, and you decide when to upgrade.

## Upgrade

```bash
npm i -g codex-multi-auth
```
