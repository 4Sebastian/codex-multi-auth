# v2.1.4

Two fixes for the Codex TUI goal proxy.

## Fixes

- The goal proxy now handles snake-case `thread_id` request bodies, and returns a local fallback when a goal read is blocked.
- Workspace-disabled and deactivated accounts now stay visible and disabled at runtime, instead of being hidden by the goal fallback.

## Upgrade

```bash
npm i -g codex-multi-auth
```
