Version resync release: v2.17.1 was prepared but never published — npm, the git tag, and the GitHub release all went straight to 2.17.2, which carries every fix listed below. Landed as #706 plus a locale fix on main. For the full prepared notes see [v2.17.1](v2.17.1.md).

## Fixed

- Automatic first-use checks prime each saved account's selected workspace independently: quota observations are keyed by the credential record and the exact workspace, so members of a shared organization no longer collide on a single organization id, and a Personal-workspace check no longer deletes the organization binding's valid entry. (#706)
- Quota cache writes merge under the cross-process file lock against a pre-edit baseline, so a background save from an older session can no longer discard a workspace observation another process just wrote. (#706)
- Pending rotated credentials carry `recordId`, so an account whose token refresh persisted through the pending-auth journal keeps its identity key and is not probed twice. (#706)
- `unbind-app` and helper cleanup verify process start times on non-English POSIX systems: the `ps -o lstart=` probe pins `LC_ALL=C`, matching `scripts/codex.js`. Previously the probe could never parse the localized output, every identity check failed, and unbind left live router/helper processes behind. ([fc37c3ec](https://github.com/ndycode/codex-multi-auth/commit/fc37c3ec))
