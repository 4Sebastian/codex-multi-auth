# v1.1.10

Adds `best`, and workspace bindings no longer get lost on token refresh.

## What's new

- `codex-multi-auth best` switches your active account to whichever one the forecast says is best right now.

## Fixes

- Workspace bindings now survive a token refresh, including workspaces that change after login.
- Rotated access, refresh and ID tokens now stay in sync when you switch or are already on the best account, instead of drifting into a mismatched set.
- Fixed install instructions that could cause an npm `EEXIST` collision with an official Codex install.

## Upgrade

```bash
npm i -g codex-multi-auth
```
