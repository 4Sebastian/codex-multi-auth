# v1.2.6

Usage counters now move for forwarded commands.

## Fixes

- Requests made through wrapped non-auth commands, like a real `codex exec`, didn't update the runtime counters, so `status` and `report --json` showed no activity. They count now.
- Nothing gets counted twice: the wrapper skips recording when the plugin has already recorded the request.

## Upgrade

```bash
npm i -g codex-multi-auth
```
