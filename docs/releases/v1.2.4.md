# v1.2.4

Storage recovery fixes ([#356](https://github.com/ndycode/codex-multi-auth/pull/356)).

## Fixes
- Recovery no longer reports success when saving the backup failed, so you're no longer told your accounts were recovered when they weren't.
- Brought back retries for transient Windows `EBUSY` locks on flagged-account backup and legacy reads, which an earlier change had dropped.

## Upgrade
```bash
npm i -g codex-multi-auth
```
