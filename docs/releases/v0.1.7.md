# v0.1.7

The first combined release of `codex-multi-auth`: runtime, TUI, account management and docs in one package, now Codex-only.

## What's new
- Storage recovery with a rotating backup fallback.
- If your main storage turns out to hold fixture data instead of your accounts, a real backup gets promoted automatically.

## Fixes
- Windows: global command routing is more reliable across `codex.bat`, `codex.cmd` and `codex.ps1`, including replacing stock shims and finding the shim from the invocation path first.
- Account switching in the Codex CLI is more stable.
- Storage identity no longer breaks when you change worktree branches.

## Upgrade
```bash
npm i -g codex-multi-auth
```
