# v2.8.3

A small quota display fix after v2.8.2. Nothing to migrate.

## Fixes
- Quota windows with no label, duration or reset time no longer show as a fake permanent `100%`. They're hidden now. ([#657](https://github.com/ndycode/codex-multi-auth/pull/657))
- Windows with real data still show.
- The dashboard no longer shows an empty `live session OK ()` when both windows have nothing useful.

## Upgrade
```bash
npm i -g codex-multi-auth
```
