# v0.1.8

Adds Codex CLI sync, and deleted accounts no longer come back.

## What's new
- Codex sync: target detection, import adapters, named backup wrappers, and sync orchestration around the existing storage model.

## Fixes
- If a clear partly failed, recovery could restore the accounts you meant to delete. An intentional clear now stops that.

## Heads up
- Codex CLI state is mirror-only. It gets read and written, but this package's storage stays the source of truth.

## Upgrade

```bash
npm i -g codex-multi-auth
```
