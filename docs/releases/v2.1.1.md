# v2.1.1

Local commands no longer get sent to the official Codex CLI by mistake.

## Fixes
- `usage`, `account`, `budget`, `bridge`, `integrations`, `models` and `monitor` are handled locally again, instead of being forwarded to official Codex and failing or doing something unexpected.
- `bridge token list --json` now returns valid JSON when the token store is empty.

## Heads up
- `bridge token list --json` was including token hashes in its output. It no longer does.

## Upgrade
```bash
npm i -g codex-multi-auth
```
