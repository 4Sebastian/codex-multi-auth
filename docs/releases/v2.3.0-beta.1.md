# v2.3.0-beta.1

Login now tells you what it really did, and `--manual` stops calling every failure a cancellation. Closes [#512](https://github.com/ndycode/codex-multi-auth/issues/512).

## Fixes

- Login printed `Added account` even when a same-email login on a different workspace was folded into an existing entry. It now says `Added account`, `Updated existing account` or `Rebound workspace for existing account`, based on what was actually saved.
- Workspaces are now saved, so `codex-multi-auth workspace <account>` works after a same-email multi-workspace login.
- Per-workspace enabled/disabled state survives re-logins, and `login --org <id>` now tracks workspaces too.
- The first workspace-aware re-login of an older account shows `Updated existing account`, not `Rebound workspace`.
- `--manual` no longer reports every failure as "Cancelled". A malformed callback URL or an OAuth state mismatch now exits non-zero with its own message. A real cancel works as before.

## Upgrade

```bash
npm i -g codex-multi-auth@beta
```
