# v2.1.12

Your Codex hooks now run when runtime rotation is on.

## Fixes
- Runtime rotation runs Codex against a temporary copy of your config, and your `[hooks.state.*]` blocks weren't copied over. Hooks set in your real `config.toml` silently didn't run.
- Those blocks are now carried over when the hook key points at your own `hooks.json`, with the path updated to the copy.
- CRLF line endings, full table bodies, unrelated hook entries, alternate hook files and existing entries are left as they were.

## Upgrade
```bash
npm i -g codex-multi-auth
```
