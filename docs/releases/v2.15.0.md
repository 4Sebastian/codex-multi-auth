# v2.15.0

Image generation and edit requests now flow through the authenticated runtime
rotation proxy, and built-in image_gen is exposed to Codex 0.154.0 sessions
without switching to native authentication or renaming the provider.

Landed as [#694](https://github.com/ndycode/codex-multi-auth/pull/694) and
[#695](https://github.com/ndycode/codex-multi-auth/pull/695).

## Upgrade notes

No migration is required. Existing accounts, pools and configuration are unchanged.

```bash
npm i -g codex-multi-auth
codex-multi-auth --version
```

The command should report `2.15.0`.
