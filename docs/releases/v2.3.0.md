# v2.3.0

Fixes a permanent `503` that could lock up rotation even when your accounts were healthy. This promotes the `2.3.0-beta` line to stable, including beta.1 through beta.3.

## Fixes
- Fixed a deadlock where you'd get `503 All managed Codex accounts are temporarily unavailable for this runtime request.` forever while `doctor` said everything was fine ([#606](https://github.com/ndycode/codex-multi-auth/issues/606)).
- Recovery now runs when accounts are rate-limited or cooling down. It's only skipped for `policy-blocked`.
- Recovery's reload now clears saved cooldowns and rate-limit windows instead of restoring them, and saves the cleared state so it survives a restart.
- A cooldown for an account missing its `accountId` is now saved, so a restart within 30 seconds no longer picks the broken account again.
- A short-retry `429` rate-limit window is now saved before retrying, so a crash mid-retry no longer loses it.

## Heads up
- `codex-multi-auth rotation reset-rate-limits` still works if you need to clear things by hand.
- PRs: [#607](https://github.com/ndycode/codex-multi-auth/pull/607), [#608](https://github.com/ndycode/codex-multi-auth/pull/608), [#609](https://github.com/ndycode/codex-multi-auth/pull/609).
