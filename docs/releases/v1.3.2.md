# v1.3.2

Interactive Codex sessions launched through the wrapper work again.

## Fixes
- Interactive (TTY) sessions now get your terminal directly instead of having their output captured, which broke them ([#437](https://github.com/ndycode/codex-multi-auth/pull/437)).
- Non-TTY runs still capture output, so unsupported-model fallback can read the error and retry.
- If the wrapper fails to launch, you now get the normal clean failure even when `spawn()` throws right away, which is what happens on Windows.

## Upgrade
```bash
npm i -g codex-multi-auth
```
