# v0.1.9

Business accounts no longer overwrite each other.

## Fixes
- Seats on the same business workspace share an `accountId`, so signing into one seat overwrote the others, especially seats with no email. Each seat now stays separate. ([#90](https://github.com/ndycode/codex-multi-auth/pull/90))
- This works the same across login, refresh, recovery, restore and import.

## Upgrade
```bash
npm i -g codex-multi-auth
```
