# v2.1.0

Adds local usage tracking, spending guards and an optional API bridge.

## What's new
- Local usage tracking, account policy metadata, routing profiles and budget guards. Usage is logged to a local JSONL ledger.
- Two new commands:

```bash
codex-multi-auth usage      # what you've spent
codex-multi-auth monitor    # watch it live
```

- Model and account capability views. Policy is now checked *before* an account is picked, not after a request fails.
- Optional local bridge: a loopback-only HTTP server with `/health`, `/v1/models` and `/v1/responses`, and hashed client-token storage. Off unless you turn it on.
- `rotation reset-rate-limits` clears stale runtime timers when the pool gets stuck.

## Fixes
- Account emails are now masked in proactive-refresh logs.

## Heads up
- Usage data stays on your machine. Nothing is reported anywhere.

## Upgrade
```bash
npm i -g codex-multi-auth
```
