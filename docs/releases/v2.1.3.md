# v2.1.3

Repairs a corrupted session index.

## Fixes
- Sessions started through the wrapper now repair `session_index.jsonl` when a known thread-store write damages it.
- The repair only runs when real session metadata backs it up, and two sessions can't repair the same file at once.
- App-bind status warnings now check your actual status path first, so the history-visibility and model-speed advice matches your setup.
