# v2.0.1

Runtime rotation is now on by default, so failover across your accounts works with no setup.

## Fixes
- Install and update now repair the packaged Codex app bind and launcher routing, so an upgrade doesn't leave them pointing at the wrong place.
- Live quota probes and fallback models now use current selectors, including `gpt-5.3-codex` and `gpt-5.5`.

## Heads up
- The rotation proxy from v2.0.0 was opt-in. It's now enabled out of the box. To turn it off:

```bash
codex-multi-auth rotation disable
```

- Or set `codexRuntimeRotationProxy=false`, or `CODEX_MULTI_AUTH_RUNTIME_ROTATION_PROXY=0`.

## Upgrade
```bash
npm i -g codex-multi-auth
```
