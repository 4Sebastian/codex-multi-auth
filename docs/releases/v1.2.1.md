# v1.2.1

Adds `forecast --explain`, plus a few fixes and docs updates.

## What's new

- `codex-multi-auth forecast --explain` shows the reasoning behind a forecast, not just the result.
- Beginner onboarding is simpler, command guidance is refreshed, and maintainer runbooks were added.
- The package also gained subpath exports with tighter coverage of what's actually shipped.

## Fixes

- Wrapper version flags (`--version` and friends) now behave correctly.
- Exporting storage with an empty account pool now works.
- GPT-5 model routing now matches current OpenAI defaults.

## Upgrade

```bash
npm i -g codex-multi-auth
```
