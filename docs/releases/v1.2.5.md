# v1.2.5

Stops runaway retries across your whole account pool and shows you more about what's going on ([#387](https://github.com/ndycode/codex-multi-auth/pull/387)).

## What's new
- `status` and `report --json` now show runtime counters, cooldown state, why an account was picked, and storage health.
- `report` can now inspect state without hitting every account:

```bash
codex-multi-auth report --cached-only
codex-multi-auth report --max-accounts 3
codex-multi-auth report --max-probes 5
```

## Fixes
- Retries and failover are tighter for `429`s, upstream `5xx` bursts, empty responses, stream replay, quota deferral, cooldown drift and usage-limit `404`s.
- Windows and storage: storage-health checks, atomic cache and snapshot writes, quieter write-ahead-log recovery checks, cleanup retried through transient `EBUSY`/`EPERM` locks, and safer live-sync and session-affinity writes.

## Heads up
- Whole-pool replay is now off by default. Before, one prompt could retry across every account even when they were all rate-limited. Outbound attempts per prompt are also capped.

## Upgrade
```bash
npm i -g codex-multi-auth
```
