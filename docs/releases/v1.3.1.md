# v1.3.1

Turns on GPT-5.5 and GPT-5.5 Pro.

## What's new
- GPT-5.5 and GPT-5.5 Pro are tried first on Codex runtimes that support them. Older runtimes and accounts without access still fall back the same predictable way.

## Fixes
- Fallback to `gpt-5.4` is stricter. It now only happens after a real upstream "unsupported model" or "no access" response, not on any error that looked related.
- A broad hardening pass across request handling, auth, account management, recovery, storage, settings, UI and shutdown: rate-limit backoff, token redaction, SSE buffering, account removal, manual-paste state, import size caps, OAuth state checks, retry writes and cleanup idempotency.

## Upgrade
```bash
npm i -g codex-multi-auth
```
