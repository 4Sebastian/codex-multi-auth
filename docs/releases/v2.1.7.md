# v2.1.7

Follow-up to v2.1.6: the `preuninstall` hook it added never ran, so it's gone. Uninstall is now a two-step manual process.

## Fixes
- `--dry-run` now works out the `bun.lock` decision from your real plugin list instead of saying "uncertain".
- `--clear-accounts` now warns and exits non-zero when nothing handles it, instead of silently doing nothing.
- Accounts with no account id no longer merge into each other during email hydration, so a refreshed token lands on the right account.
- Restoring a missing `model_provider` or response-storage key no longer produces invalid TOML that Codex can't parse.
- Transient Windows file locks during `fix`, health checks and quota-cache saves are now a warning, not a hard failure.
- App-bind won't point `config.toml` at a dead router anymore. It needs a running, live router first.

## Heads up
- `npm@7+` doesn't run `preuninstall`, so the hook from v2.1.6 was removed. To uninstall fully, run both:

```bash
codex-multi-auth uninstall
npm uninstall -g codex-multi-auth
```

- The first command undoes what postinstall did: unbinds app rotation, removes launchers, removes the plugin entry from `Codex.json`, clears the module cache, and deletes a shared `bun.lock` only if no other Codex plugins are left.

## Upgrade
```bash
npm i -g codex-multi-auth
```
