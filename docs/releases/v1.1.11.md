# v1.1.11

Accounts that share an email no longer mix up each other's quota data.

## Fixes
- Two accounts on the same email in different workspaces shared a quota cache key, so one overwrote the other's quota data ([#122](https://github.com/ndycode/codex-multi-auth/pull/122)).
- Live quota fallback state now stays separate per account after `check` and `fix` refresh shared identity fields.
- A failed cache save no longer corrupts the quota data you already had loaded.

## Upgrade
```bash
npm i -g codex-multi-auth
```
